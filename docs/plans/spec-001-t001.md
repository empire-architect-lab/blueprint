## Risks

1. **JetBrains Mono variable woff2 is not distributed by JetBrains.** Their official zip ships variable as `.ttf` only and per-weight `.woff2` files. Decision: vendor `JetBrainsMono-Regular.woff2` for M1; revisit if multi-weight mono is needed in a later task. Documented in tasks.md.
2. **Tailwind 4 has no `tailwind.config.ts`.** The T001 brief references registering fonts in `tailwind.config.ts`, but the project uses Tailwind 4 with `@theme inline` in `globals.css`. Plan: register the new `--font-display`, `--font-mono`, `--font-body`, `--font-heading` tokens in the existing `@theme inline` block.
3. **Throwaway `<h1>` visual confirmation.** The brief calls for a temporary `<h1 className="font-display text-[220px]">test</h1>` to eyeball-check, then delete before commit. Skipping the throwaway insertion entirely — `npm run build` + the existing e2e accessibility test cover the build-time correctness, and Opus does the visual confirmation against the Vercel preview after merge.
4. **Plausible script + middleware deprecation warnings** are pre-existing and unrelated to T001.

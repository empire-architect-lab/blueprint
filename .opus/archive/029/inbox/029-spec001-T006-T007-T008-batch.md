## Sub-task A — T006 — Cinematic state machine

- `src/lib/animations/cursor-state.ts` (new)
- `tests/unit/cursor-state.test.ts` (new)
- `specs/001-the-cursor/tasks.md` — tick T006 boxes in THIS commit

### Spec
- `export type CursorState = "IDLE" | "TYPING" | "PAUSE_1" | "ENTER" | "COMMIT_REVEAL" | "PAUSE_2" | "DISSOLVE" | "EARTH" | "PIPELINE_SCROLL" | "WHITE_FLASH" | "HERO_REVEALED"`
- `export type CursorAction = { type: "TICK_TYPING" } | { type: "START_PAUSE_1" } | { type: "PRESS_ENTER" } | { type: "REVEAL_COMMIT" } | { type: "START_DISSOLVE" } | { type: "EARTH_READY" } | { type: "PIPELINE_PROGRESS"; value: number } | { type: "TRIGGER_FLASH" } | { type: "REVEAL_HERO" } | { type: "SKIP" } | { type: "REPLAY" }`
- `export const initialCursorState: CursorState = "IDLE"`
- `export function cursorReducer(state, action): CursorState`

### Legal transitions (every other pair is illegal)
- `IDLE + TICK_TYPING → TYPING`
- `TYPING + START_PAUSE_1 → PAUSE_1`
- `PAUSE_1 + PRESS_ENTER → ENTER`
- `ENTER + REVEAL_COMMIT → COMMIT_REVEAL`
- `COMMIT_REVEAL + START_DISSOLVE → PAUSE_2`
- `PAUSE_2 + START_DISSOLVE → DISSOLVE`
- `DISSOLVE + EARTH_READY → EARTH`
- `EARTH + PIPELINE_PROGRESS → PIPELINE_SCROLL`
- `PIPELINE_SCROLL + PIPELINE_PROGRESS → PIPELINE_SCROLL` (idempotent)
- `PIPELINE_SCROLL + TRIGGER_FLASH → WHITE_FLASH`
- `WHITE_FLASH + REVEAL_HERO → HERO_REVEALED`
- `* + SKIP → HERO_REVEALED` (from any state; no-op from HERO_REVEALED)
- `HERO_REVEALED + REPLAY → IDLE`

### Illegal transition behavior
- Dev (`process.env.NODE_ENV !== "production"`): throw `Error("Illegal transition: <state> + <action.type>")`
- Prod: return existing state unchanged (no-op, no throw)

### Tests
Walk the full 11×11 transition matrix programmatically. Every legal pair asserted positively. Every illegal pair asserted twice (throws in dev via `vi.stubEnv("NODE_ENV", "development")`, no-ops in prod via `vi.stubEnv("NODE_ENV", "production")`). SKIP from all 11 states → HERO_REVEALED. REPLAY from HERO_REVEALED → IDLE; REPLAY from the other 10 states → illegal behavior.

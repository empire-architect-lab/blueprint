`memory/constitution.md` becomes a **one-line pointer file** that redirects any reader (human or AI) to the canonical. Update project `CLAUDE.md` to point at the canonical path directly so future Opus conversations read the right file.

## Steps

```bash
git fetch origin
git push origin --delete spec/001-the-cursor
git branch -d spec/001-the-cursor 2>/dev/null || true
```

Log branch deletion confirmation to `.logs/012-cleanup.log`.

### Part B — unify constitution

1. Create a new branch from latest main: `chore/012-unify-constitution`
2. **Diff the two files first.** Run `diff memory/constitution.md .specify/memory/constitution.md > .logs/012-constitution-diff.log`.    - Replace `memory/constitution.md` contents with exactly this (no frontmatter, no preamble):

   - Same in `SEED.md` if referenced there.
4. Commit: `chore(constitution): unify on .specify/memory/constitution.md as canonical`
5. Open PR #N to main. Title: `chore(constitution): unify on .specify/memory/constitution.md as canonical`. Body: link to this task file.
6. Wait for CI green. Do NOT self-approve. Stop. Let Opus review + bot-approve in a follow-up task.
